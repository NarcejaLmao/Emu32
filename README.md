# 🎮 Emu32 🎮
Emu32 is a 100% free retro and open-source emulation firmware for ESP32's that runs all your favorite classic systems off the SD card. We aim to have the best emulation experience possible on the ESP32 and will continue to get new supported ESP32 systems, new supported systems, bug fixes and much more over time.
