# 🎮 Emu32 🎮
Emu32 is a free and open-source retro emulation firmware for ESP32's that runs all your favorite classic systems off the SD card. We aim to have the best emulation experience possible on the ESP32 and will continue to get new supported ESP32 systems, new supported systems, bug fixes and much more over time.

# Supported Systems
Nintendo Entertainment System<br>
Nintendo Gameboy<br>
Atari 2600

# Supported ESP32 Systems
Waveshare ESP32 C6 1.47 Inch LCD Dev Board<br>
Waveshare ESP32 S3 1.47 Inch LCD Dev Board
